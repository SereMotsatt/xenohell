# Xenohell (EN PROGRESO)
El infierno de los aliens.

## Aviso
Este proyecto tiene muy poco progreso, si usted desea experimentarlo hoy no espera a que los crafteos o herramientas se queden igual. 


## Curiosidades
### ¿Porqué se llama "Xenohell"?
Es un intento por mesclar "Xeno" (extraño) que se suele usar para lo alienigena con hell (infiero).
### ¿Cual es el futuro del proyecto?
Pretendo llevar un progreso lento en este proyecto debido a que no tengo mucho tiempo libre, no prometo continuarlo si pierdo el interés.
### ¿Por qué un infierno alienígena y que tendrá de especial?
Hace unos años recientes, intenté hacer un juego para Luanti (Anteriormente Minetest) inspirado en el infierno teológico, sin embargo, perdí mi progreso por problemas en el hardware de mi PC.

## Como Instalarlo
### Paso 1
Necesitas Descargarte e instalarte Luanti.
### Paso 2
Ve al último lanzamiento de este repositorio y descargue la última version (Presione donde dice Source code (zip)).
### Paso 3
Copie el archivo descargado y acceda al directorio de datos de usuario de Luanti (cree una carpeta llamada "games" si no la encuentra).
Dentro de esa carpeta pegará el archivo descargado y lo descomprimirá.

Tiene que quedar algo así (games/xenohell-x.x.x.x).
Ahora tendrá que renombrar la carpeta "xenohell-x.x.x.x" a "xenohell" y estará listo.

### Paso 4
A disfrutarlo... o por lo menos probarlo, recuerde que este juego está en progreso.
